Install

  1. Download Storm-Setup.exe using the button above.
  2. Optional: verify the checksum (below) to make sure the file wasn't tampered with.
  3. Run the installer. If Windows SmartScreen shows a notice for new software, choose More info → Run anyway after verifying.
  4. On first launch, import from Chrome, Edge, Firefox, Brave or Opera if you like, then ride the lightning.

Verify your download

Every Storm release is digitally signed, and the auto-updater checks the signature of each update before installing it. You can also compare the installer's SHA-256 checksum:

SHA-256,

In PowerShell, run this in your Downloads folder and check that the output matches:

Get-FileHash .\Storm-Setup.exe -Algorithm SHA256

You can also right-click the file → Properties → Digital Signatures to see the signer.

Only download Storm from this site. Copies from other places may be modified. If a checksum doesn't match, don't run the file.
