What you need

  • Windows 10 or 11, 64-bit.
  • Microsoft Edge WebView2 Runtime. It's already on Windows 11 and most up-to-date Windows 10 PCs. If it's missing, get the free Evergreen runtime from Microsoft.
  • .NET 8 is included, so there's nothing extra to install.
  • For the free AI: a reasonably modern graphics card. Optional.

Check your download

Storm isn't code-signed yet, so here's how to make sure your copy is the real one. Its SHA-256 checksum should match this:

In PowerShell, in your Downloads folder, run:

Get-FileHash .\Storm.exe -Algorithm SHA256

Updates are different: Storm checks each update's signature before installing it.

Only download Storm from this site. If a checksum doesn't match, don't run the file.
